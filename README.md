# Engineer Game: Live Coding

A collection of classic coding-interview problems, solved in Python while practicing live-coding technique — talking through the approach, reasoning about data structures before writing code, and building up each solution incrementally.

## Getting started

This project uses [uv](https://docs.astral.sh/uv/) for dependency management and requires Python 3.12+.

```bash
uv sync
```
