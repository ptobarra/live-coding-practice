# Engineer Game: Live Coding

A collection of classic coding-interview problems, solved in Python while practicing live-coding technique — talking through the approach, reasoning about data structures before writing code, and building up each solution incrementally.

## Problems

| # | Problem | Solution |
|---|---------|----------|
| 1 | Two Sum | [1-two_sum.py](1-two_sum.py) |
| 2 | Valid Parentheses | [2-valid_parentheses.py](2-valid_parentheses.py) |
| 3 | Best Time to Buy and Sell Stock | [3-best_time_to_buy_and_sell_stock.py](3-best_time_to_buy_and_sell_stock.py) |
| 4 | Merge Two Sorted Lists | [4-merge_two_sorted_lists.py](4-merge_two_sorted_lists.py) |
| 5 | Thread-Safe Metrics Aggregation | [Thread_safe_metrics_aggregation.py](Thread_safe_metrics_aggregation.py) |

## Getting started

This project uses [uv](https://docs.astral.sh/uv/) for dependency management and requires Python 3.12+.

```bash
uv sync
```
